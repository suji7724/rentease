# 🏠 RentEase – Full-Stack Property Listing Platform

**RentEase** is a modern full-stack property rental platform that allows users to browse, list, manage, and discover rental properties through a clean and responsive interface.

🔗 **Live Demo:** https://rentease-iota.vercel.app/
🔗 **Backend API:** https://rentease-1-25dv.onrender.com

---

## 🚀 Key Features

### 🔐 Secure Authentication & Authorization

* JWT-based user authentication
* Protected routes and secure API access
* User-specific property management

### 🏡 Property Management

* Create, Read, Update, and Delete (CRUD) property listings
* Manage rental properties with ease
* Dynamic property data storage using MongoDB

### 📱 Responsive User Experience

* Fully responsive design for desktop, tablet, and mobile devices
* Modern UI built with React and Tailwind CSS
* Fast and intuitive navigation

### ☁️ Production Deployment

* Frontend deployed on Vercel
* Backend deployed on Render
* Cloud-hosted MongoDB database

---
